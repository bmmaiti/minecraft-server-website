# 阿里云函数计算部署指南

## 部署步骤

### 1. 准备工作

1. 确保已安装阿里云 CLI：https://help.aliyun.com/document_detail/121130.html
2. 配置阿里云 AccessKey：`aliyun configure`
3. 创建函数计算服务

### 2. 部署函数

```bash
# 进入函数目录
cd aliyun-function

# 安装依赖
npm install

# 使用 Serverless Devs 部署（推荐）
s deploy
```

### 3. 配置定时触发器

在阿里云控制台配置定时触发器：

1. 进入函数计算控制台
2. 找到刚创建的函数
3. 创建触发器
4. 触发器类型：定时触发器
5. Cron 表达式：`0 2 * * *` (每天凌晨 2 点)
6. 输入参数：空

### 4. 配置存储

将下载的 logo 上传到阿里云 OSS：

1. 创建 OSS Bucket
2. 配置函数访问 OSS 的权限
3. 修改代码将 logo 上传到 OSS

## Cron 表达式说明

- `0 2 * * *` - 每天凌晨 2 点
- `0 3 * * *` - 每天凌晨 3 点
- `0 4 * * *` - 每天凌晨 4 点

## 注意事项

1. 函数超时时间设置为 300 秒
2. 内存建议 512MB
3. OSS Bucket 需要开启公共读权限
4. 定时任务需要函数计算服务有访问 OSS 的权限

## 成本估算

- 函数计算：免费额度内（每月 100 万次调用）
- OSS：少量存储费用（约 0.12 元/GB/月）
- 流量：少量外网流量费用
