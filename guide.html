二、怎么进服

正版账号

直接用正版登录器进服，自动走正版验证，什么都不用配置。

离线账号（LittleSkin）

  1. 去 LittleSkin（littleskin.cn）注册账号
  2. 认证方式选「外置登录 / Yggdrasil」
  3. 认证服务器填 https://littleskin.cn/api/yggdrasil
  4. 用 LittleSkin 的账号密码登录

同一个名字不要混用两种认证方式。 先用离线后改用 LittleSkin，UUID 会变，插件会报数据冲突，需要找管理迁移数据。

三、第一件事：圈地

不圈地就可能被拆家。进服先拿一根木棍，左键点一个角、右键点对角，然后执行：

/dom create 我的家 — 创建领地

/dom list — 查看自己的领地

/dom trust 玩家名 — 给某个玩家权限

/dom delete 名字 — 删除领地
