# 图片使用说明

此目录用于存放网站文章的图片文件。

## 当前网站使用的图片文件：

1. post1.jpg - 学习前端开发的心得与体会
2. post2.jpg - CSS Grid布局完全指南
3. post3.jpg - JavaScript异步编程详解

## 解决方案：

1. **添加实际图片**：
   - 将您自己的图片文件重命名为post1.jpg、post2.jpg、post3.jpg
   - 放置在此目录中

2. **使用在线图片服务**：
   - 可以使用免费的在线图片服务，如：
     - https://picsum.photos/
     - https://placeholder.com/

3. **使用占位图片服务**：
   - 可以直接在HTML中使用在线占位图片服务：
     ```html
     <img src="https://picsum.photos/600/200?random=1" alt="文章图片" class="post-img">
     ```

## 建议的图片尺寸：
- 宽度：600px
- 高度：200px
- 格式：JPG或PNG
